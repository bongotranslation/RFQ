# Changelog

Все важные изменения в проекте будут документированы в этом файле.

## [Неопубликованная версия] - 2024-12-19

### Исправлено
- **Упрощена структура JSON**: Убраны избыточные поля `words_total`, `words_by_language`, `images_total` из узла `pdf_stats`. Эти данные теперь доступны только в узле `summary`, вычисляются динамически из данных по страницам

## [Предыдущие изменения] - 2024-12-19

### Добавлено
- **Подсчет слов по языкам**: Добавлена функциональность определения и подсчета слов для каждого языка в тексте
- **OCR интеграция с обновлением статистики страниц**: Теперь после выполнения OCR количество слов на странице автоматически обновляется
- Подсчет слов в результатах OCR (`ocr_vision.py`)
- Функция `update_pdf_stats_with_ocr()` для обновления статистики PDF после OCR (`pdf_utils.py`)
- Новые поля в статистике страниц:
  - `words_by_language`: количество слов по языкам на странице (включает OCR)
  - `ocr_applied`: флаг применения OCR к странице
- Новые поля в общей статистике:
  - `words_by_language`: общее количество слов по языкам (включает OCR)
- Новые поля в summary:
  - `words_by_language`: подсчет слов по языкам в кратком отчете (включает OCR)

### Изменено
- **Алгоритм определения языка**: Реализована эвристика на основе символов (кириллица для русского, латиница для английского)
- **Логика обработки OCR**: OCR результаты теперь интегрируются в основную статистику PDF с учетом языков
- **Эвристика определения необходимости OCR**: Теперь OCR требуется для всех изображений >0.2% площади страницы (вместо только больших изображений >50%)
- `needs_ocr` устанавливается в `false` для страниц после применения OCR
- Обновленный подсчет `words_total` включает как исходные, так и OCR слова
- Расширенная информация в API ответах с детализацией OCR результатов и языковой статистикой

### Исправлено
- **Проблема с нулевым количеством слов на страницах с изображениями**: Теперь OCR правильно распознает текст из изображений и обновляет счетчик слов
- Корректная интеграция OCR результатов в общую статистику документа

### Техническое
- Добавлены функции `_count_words_by_language()` в `ocr_vision.py` и `pdf_utils.py`
- Улучшена модульность кода с выделением функции обновления статистики
- Добавлены комментарии для лучшей читаемости кода
- Оптимизирована логика определения необходимости повторного OCR
- Создан и протестирован полный цикл OCR: от определения `needs_ocr` до обновления статистики
- Проверена работа Google Cloud Vision API интеграции
- Реализована агрегация языковой статистики на уровне страниц и документа
